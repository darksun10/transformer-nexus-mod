# Lore Framework

## Transformers
The framework supports Transformers concepts such as Cybertron, Cybertronians, Autobots, Decepticons, Primes, Energon and transformation states.

## Nexus Universe
Kairos is the hidden overseer of the Nexus Universe. Verticons are an original Cybertronian faction created for the server, with their leader connected to Kairos.

The architecture keeps original Nexus material separate from Transformers-side data so both can coexist.

The repository does not include proprietary artwork or long copyrighted Transformers text.
