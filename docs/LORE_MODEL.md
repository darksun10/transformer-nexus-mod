# Lore Model

The plugin uses two namespaces:

`TRANSFORMERS`
Canonical Transformers-inspired records and gameplay concepts.

`NEXUS`
Original Nexus Universe records.

A character can reference both. Example:

- Name: Verticon Leader
- Origin: NEXUS
- Species: Cybertronian
- Faction: Verticons
- Canon compatibility: TRANSFORMERS
- Kairos relationship: DIRECT_CONTACT

This allows original characters to exist inside a Transformers-compatible setting without overwriting the Nexus Universe's own story.
