# Nexus Universe Transformers Architecture

This project is designed as a server-side Paper framework where Transformers canon and Nexus Universe original lore coexist.

## Lore layers

1. Transformers Canon
   - Cybertron
   - Autobots
   - Decepticons
   - Primes
   - Cybertronians
   - Energon
   - Canon characters and factions

2. Nexus Universe Original Lore
   - Kairos
   - Verticons
   - Custom characters
   - Nexus-specific factions, ranks, events and story

Canon and original content are intentionally separated so future contributors can expand either layer without rewriting the other.

## Systems

- `lore/` — lore records and categories
- `characters/` — character profiles
- `factions/` — faction definitions
- `kairos/` — Kairos narrative/system hooks
- `abilities/` — server-side abilities
- `transformations/` — future transformation mechanics
- `events/` — future story events
